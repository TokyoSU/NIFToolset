NIFToolset uses vcpkg manifest mode (vcpkg.json).

Required packages are:
- bgfx[tools]
- SDL3
- assimp
- tinyxml

For manual classic-mode installation, use the matching triplet, for example:

    vcpkg install bgfx[tools]:x64-windows-static sdl3:x64-windows-static assimp:x64-windows-static tinyxml:x64-windows-static

The legacy dxsdk-d3dx dependency was removed with the DX9/D3D10/D3D11 renderers.
